Pas un antivirusUn format reconnu ne garantit ni sécurité ni compatibilité ChromeOS.

Session Windows distante

Le bureau est diffusé par Guacamole en HTML5 sur HTTP(S)/WebSocket. Il faut un serveur Guacamole et un PC Windows allumé.

N'expose jamais le port RDP 3389 directement sur Internet. Utilise HTTPS, une authentification forte et un réseau privé/VPN. Ne stocke pas tes identifiants ici.

Déploiement

1. Serveur LinuxDocker et Docker Compose, sur un serveur que tu administres.
2. Guacamole + HTTPSLe dossier deploy contient une base Docker Compose et un exemple Caddy.
3. Machine WindowsWindows Pro/Enterprise/Education configuré pour RDP. Windows Home ne peut généralement pas héberger RDP.
4. ConnexionCrée la connexion RDP dans Guacamole, puis colle son URL HTTPS ici.

Ce qui n'est pas fourni

GitHub Pages ne fournit pas de machine Windows, de calcul distant, de stockage privé ni de streaming. Le serveur et le PC Windows doivent être fournis. Guacamole est adapté au bureau distant, pas au jeu vidéo à faible latence.

ChromePort Ultimate est un prototype indépendant. N'exécute aucun fichier inconnu. L'analyse locale ne transmet pas les installateurs.
